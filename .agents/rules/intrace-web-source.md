# inTrace Web Frontend Source Reference

- **Đường dẫn mã nguồn Web:** `D:\Source\intrace\frontend-dev`
- **Mô tả:** Dự án Angular frontend của hệ thống web inTrace (IntrustDSS Trace).
- **Mục đích:** Khi cần đối chiếu logic nghiệp vụ, gọi API, payload dữ liệu hoặc giao diện giữa Mobile App và Web, luôn tra cứu và đối chiếu với mã nguồn tại thư mục này.
